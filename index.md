# virtu

**Android ARM64 virtual machine app – run Windows, macOS, and Linux on your phone.**

[![Download APK](https://img.shields.io/badge/Download-APK-blue?style=for-the-badge)](https://github.com/virtu-support/virtu/releases)
[![GitHub](https://img.shields.io/badge/GitHub-181717?style=for-the-badge&logo=github)](https://github.com/virtu-support/virtu)

## Features

- Linux via proot (no root)
- Windows & macOS via QEMU
- VNC display with touch controls
- Save state, shared clipboard, audio
- Custom installer with curl

## Quick Start

```bash
git clone https://github.com/virtu-support/virtu.git
cd virtu
./gradlew assembleDebug
```
